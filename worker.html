Cloudflare ড্যাশবোর্ডে Worker তৈরি করুন

Cloudflare ড্যাশবোর্ডে লগইন করে বামপাশের মেনু থেকে Workers & Pages ➔ Create Application ➔ Create Worker এ ক্লিক করে যেকোনো নাম দিয়ে Save করুন।

২

কোড পেস্ট করে Deploy দিন

Worker-এর ভেতরের Quick Edit বা কোড এডিটরে যান। ওপরের কোড বক্স থেকে Copy Code বাটনে ক্লিক করে পুরো কোডটি Worker-এ পেস্ট করে দিন এবং Deploy বাটনে ক্লিক করুন।

৩

কাস্টম রুট বা ডোমেইন কানেক্ট করুন

Worker টির Settings ➔ Triggers ➔ Custom Domains বা Routes এ গিয়ে ক্লায়েন্টের ডোমেইন দিন (যেমন: clientdomain.com/api/admin-login) অথবা Worker এর ফ্রি URL (https://name.subdomain.workers.dev) ব্যবহার করুন।
